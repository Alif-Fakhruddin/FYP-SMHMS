⚙️ Ambang Nilai Amaran (Threshold Rules)

💨 Gas (MQ135)

  • Normal: < 2500 PPM Selamat
  • Warning: 2500 - 3500 PPM Amaran
  • Danger: > 3500 PPM Bahaya

🌊 Paras Air (HC-SR04)

  • Normal: > 30 cm Selamat
  • Warning: 15 cm - 30 cm Amaran
  • Danger: <= 15 cm Bahaya

🔥 Sensor Api (Flame Sensor)

  • Digital Input: Active LOW
  • Normal: HIGH (Tiada Api)
  • Danger: LOW (Api Dikesan) Bahaya
📡 Sambungan Hardware & Database

🖥️ Perkakasan (Hardware)

  • Microcontroller: ESP32 Dev Module
  • Protokol Komunikasi: Wi-Fi / HTTP REST API
  • Power Supply: 5V DC Regulator

🗄️ Pangkalan Data (MySQL)

  • Database: MySQL (XAMPP Local Server)
  • Backend Engine: Python (Flask REST API)
  • Status Sambungan: Online

ℹ️ Maklumat Projek & Ahli Kumpulan

Tajuk Projek: Smart Multi-Hazard Monitoring System (SMHMS)

Institusi: Politeknik Malaysia

Fungsi Utama: Pemantauan risiko banjir, kebocoran gas, dan amaran kebakaran secara real-time dengan integrasi pangkalan data MySQL.
